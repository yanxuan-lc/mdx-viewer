# BRIEF: 简体中文/英文与用户偏好持久化

## Current behavior

- 浏览器界面和 CLI 的固定产品文案主要为简体中文，没有统一的语言选择机制。
- 浏览器工具栏只有明暗切换按钮；主题只能在 light/dark 之间临时切换，刷新后丢失。
- 页面初始主题由 frontmatter `mode` 决定，未配置时固定为 light。
- `<html lang>` 固定为 `zh-CN`。

## Desired behavior

- 浏览器界面与 CLI 支持 `zh-CN` 和 `en` 两种产品语言。
- 工具栏在主题按钮左侧提供语言切换按钮，用户可以在两种语言间切换。
- 主题支持 `auto`、`light`、`dark` 三种偏好；`auto` 持续跟随系统明暗变化。
- 浏览器中的语言和主题手动选择写入 LocalStorage，并在后续启动时恢复。
- 未保存语言时使用浏览器语言；未保存主题时先尊重 frontmatter `mode`，否则使用 `auto`。
- CLI 语言按 `--lang`、`MDXV_LANG`、系统语言、英文兜底的顺序选择，并将初始语言注入预览或导出页面。

## Acceptance criteria

- [ ] S1：浏览器语言为简体中文且无已保存偏好时，产品 UI 首次显示中文。
- [ ] S2：浏览器语言不是简体中文且无已保存偏好时，产品 UI 首次显示英文。
- [ ] S3：点击工具栏语言按钮可在 `zh-CN` 和 `en` 间切换，产品固定文案和 `<html lang>` 同步更新，刷新后保持。
- [ ] S4：主题按钮可依次选择 `auto`、`light`、`dark`；选择立即生效并在刷新后保持。
- [ ] S5：主题为 `auto` 时，系统明暗变化会实时更新页面主题；手动 light/dark 时不跟随系统变化。
- [ ] S6：没有已保存主题时，合法的 frontmatter `mode` 生效；没有合法配置时默认 `auto`。
- [ ] S7：缺失或损坏的 LocalStorage 值不会导致页面崩溃，会回退到默认选择规则。
- [ ] S8：浏览器的导航、TOC、空状态、错误、辅助功能标签、Grid 默认筛选项和 Footer 固定措辞均有中英文文案。
- [ ] S9：`mdxv` 与 `mdxx` 支持 `--lang zh-CN|en`；无显式参数时按环境变量和系统语言回退；非法值给出本地化错误。
- [ ] S10：`mdxx` 导出的单文件仍保持零资源外链和离线可用，且语言/主题切换与持久化正常工作。
- [ ] S11：MDX 正文、frontmatter 内容、文件名和用户传入的组件文本不被自动翻译。
- [ ] S12：现有 MDX 编译兼容、目录导航和自包含导出测试保持通过。

## Out-of-scope

- 不支持 `zh-CN`、`en` 之外的语言。
- 不自动翻译 MDX 正文、frontmatter 或用户组件内容。
- 不为 demo 文档维护完整的双语内容版本。
- 不引入第三方 i18n 框架、远程翻译服务或 CDN 依赖。
